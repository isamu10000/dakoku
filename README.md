# 打刻ハブ（Claude非依存版）

VPNアプリを開く → 職場サイトを開く → 出勤・退勤を記録する、をスマホ1画面でまとめるアプリです。
HTML・CSS・JavaScriptだけで動き、サーバーもアカウントも不要です。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest | ホーム画面に追加するための情報 |
| sw.js | オフラインでも開けるようにする仕組み |
| icon-192.png / icon-512.png | アプリのアイコン |

## 使えるようにする手順

ホーム画面への追加とオフライン対応には、**https で公開する**必要があります。
次のどれかに、このフォルダの中身をそのまま置いてください。

- **GitHub Pages**: リポジトリにファイルを置き、Settings の Pages で公開します。無料です。
- **Netlify / Cloudflare Pages**: フォルダをドラッグ＆ドロップするだけで公開できます。無料です。
- **大学や職場のWebサーバー**: https で配信できる場所に置きます。

公開後のURLをスマホのChromeで開き、メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。
アプリ内の「設定」にも追加ボタンがあります。

## 使い方の設定

設定（アプリ下部）で、次を入れます。

1. 職場サイトのURL
2. 出勤と退勤の予定時刻
3. VPNアプリを開くリンク（任意）。空欄なら、AndroidではF5 Access（com.f5.edge.client_ics）を開きます。

リマインドは、設定の「カレンダー用の予定ファイルを作る」から作ります。
平日の定期予定のファイルが作られ、開くとカレンダーアプリに登録できます。通知はカレンダーアプリが出します。

## 記録について

- 記録は各自の端末のブラウザにだけ保存されます。サーバーには送られません。
- 端末を変えるときや控えを残すときは、設定の「記録をCSVで書き出す」を使います。
- ブラウザのサイトデータを消すと、記録も消えます。

## 注意

- 職場のVPNや勤怠システムの規則で、こうしたアプリの利用が制限されていないか、念のため確認してください。
- このアプリは打刻そのものは行いません。職場サイトでの打刻は自分で行い、このアプリには「打刻した」記録を残します。
- f5 Accessを開くボタンは、Androidのアプリ名（パッケージ名）を使う方式です。開かない場合は、ホーム画面から起動してください。
